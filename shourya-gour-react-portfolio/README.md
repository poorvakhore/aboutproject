# Shourya Gour — React Portfolio

A modern, dark, responsive React portfolio built around Shourya Gour's profile and interests in Computer Science & Data Science, Machine Learning, Deep Learning, AI and web development.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Edit `src/main.jsx` for profile text, projects, skills and links.
- Edit `src/styles.css` for colors, layout and typography.
- Replace the placeholder email in `src/main.jsx` with your real email.
- The LinkedIn button already points to:
  `https://www.linkedin.com/in/shourya-gour-7125b0380/`

## Notes

The portfolio intentionally avoids inventing employment history or certifications that were not clearly available from the supplied profile context. It focuses on your known direction: CSD, ML, DL, Python, web development, MLOps and practical projects such as SafePin.
